# Cheesebox
The cheesebox is a small emulation device that uses a CM5 board. It will have the power to emulate 5th-gen and select 6th- and 7th-gen hardware. I plan for it to be kind of flat so I can make a screen, battery, and controller add-on down the line to make it portable. Why is it called "The Cheesebox"? Because I like cheese. Duh.

# Features

Cool Design

Power Light

Two USB-C Ports

Two USB-A 3.0 Ports

Two USB-A 2.0 Ports

Magjack Ethernet Port

3.5 mm Headphone Jack

Micro SD Card Slot

2242 M.2 SSD or NVMe Slot (3rd Gen)

HDMI Output
